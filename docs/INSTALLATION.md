# Установка UMBRA

> **Версия:** 2.1.1
> **Платформа:** Windows 10/11 (x64)

---

## 📥 Способы установки

### Способ 1: NSIS Installer (Рекомендуется)

**Для кого:** Обычные пользователи

**Файл:** `UMBRA-Setup-2.1.1.exe` (~150MB)

**Установка:**
1. Скачайте `UMBRA-Setup-2.1.1.exe` из [Releases](https://github.com/NoxirDev/umbra/releases)
2. Запустите установщик
3. Выберите язык (Русский/English)
4. Прочитайте и примите лицензию
5. Выберите папку установки (по умолчанию: `C:\Users\{User}\AppData\Local\UMBRA`)
6. Нажмите "Установить"
7. Дождитесь завершения
8. Установщик предложит запустить UMBRA

**Что устанавливается:**
- ✅ Приложение UMBRA
- ✅ Ярлык на рабочем столе
- ✅ Ярлык в меню "Пуск"
- ✅ Деинсталлятор

**Требования:**
- Windows 10/11 (64-bit)
- ~200MB свободного места
- Права пользователя (admin НЕ требуется)

---

### Способ 2: Portable версия

**Для кого:** Продвинутые пользователи, запуск с USB

**Файл:** `UMBRA-2.1.1-Portable.exe` (~150MB)

**Установка:**
1. Скачайте `UMBRA-2.1.1-Portable.exe`
2. Создайте папку (например, `D:\UMBRA`)
3. Скопируйте туда `.exe` файл
4. Запустите `UMBRA-2.1.1-Portable.exe`
5. Приложение распакуется и запустится

**Особенности:**
- ✅ Не требует установки
- ✅ Можно запускать с USB
- ✅ Настройки хранятся рядом с .exe
- ✅ Легко удалить (просто удалите папку)

**Требования:**
- Windows 10/11 (64-bit)
- ~300MB свободного места (с распаковкой)

## 🚀 Первый запуск

### После установки:

1. **Запустите UMBRA**
   - Через ярлык на рабочем столе
   - Или через меню "Пуск"

2. **Откроется окно оверлея**
   - Прозрачное окно поверх всех окон
   - Можно перемещать и изменять размер

3. **Откройте настройки**
   - Кликните правой кнопкой на иконку в трее
   - Выберите "Настройки"

4. **Настройте интеграции**
   - Twitch: введите название канала
   - DonationAlerts: введите токен
   - Kick/YouTube: по желанию

5. **Настройте внешний вид**
   - Выберите тему
   - Настройте прозрачность
   - Установите размер шрифта

6. **Готово!** 🎉

## 🔧 Настройка для OBS

### Добавление оверлея в OBS:

1. **Откройте OBS Studio**

2. **Добавьте Browser Source:**
   - Источники → Добавить → Browser
   - Имя: "UMBRA Chat" (или любое)

3. **Настройте URL:**
   ```
   http://127.0.0.1:4587/obs/chat
   ```

4. **Настройте размер:**
   - Ширина: 400
   - Высота: 600
   - (или по вашему желанию)

5. **Дополнительные страницы:**
   - Донаты: `http://127.0.0.1:4587/obs/donations`
   - Цель: `http://127.0.0.1:4587/obs/goal`
   - Алерты: `http://127.0.0.1:4587/obs/alerts`

## 🔄 Обновление

### Автоматическое обновление:
- UMBRA проверяет обновления при запуске
- Уведомление появится если доступна новая версия
- Нажмите "Обновить" для автоматической установки

### Ручное обновление:
1. Скачайте новую версию установщика
2. Запустите установщик
3. Он автоматически обновит существующую установку
4. Настройки сохранятся

## 🗑️ Удаление

### NSIS версия:

**Способ 1: Через настройки Windows**
1. Параметры → Приложения
2. Найдите "UMBRA"
3. Нажмите "Удалить"
4. Выберите, удалять ли настройки

**Способ 2: Через деинсталлятор**
1. Откройте папку установки
2. Запустите `uninstall.exe`
3. Следуйте инструкциям

**Что удаляется:**
- ✅ Файлы приложения
- ✅ Ярлыки
- ✅ Записи в реестре
- ❓ Настройки (на ваш выбор)

### Portable версия:
1. Закройте UMBRA
2. Удалите папку с приложением
3. Готово!

## ⚠️ Возможные проблемы

### Проблема 1: "Windows защитил ваш компьютер"

**Причина:** Приложение не подписано цифровой подписью

**Решение:**
1. Нажмите "Подробнее"
2. Нажмите "Выполнить в любом случае"
3. Это безопасно - UMBRA open-source

### Проблема 2: Антивирус блокирует установку

**Причина:** Ложное срабатывание на Electron приложения

**Решение:**
1. Добавьте UMBRA в исключения антивируса
2. Или временно отключите антивирус
3. Проверьте MD5/SHA256 хеш файла

### Проблема 3: Установщик не запускается

**Причина:** Поврежденный файл или нехватка прав

**Решение:**
1. Перескачайте установщик
2. Проверьте размер файла (~150MB)
3. Запустите от имени администратора

### Проблема 4: "Не удается найти модуль"

**Причина:** Неполная установка

**Решение:**
1. Удалите UMBRA
2. Переустановите заново
3. Убедитесь что установка завершилась успешно

### Проблема 5: Приложение не запускается

**Причина:** Конфликт портов или поврежденные настройки

**Решение:**
1. Закройте все экземпляры UMBRA
2. Удалите файл настроек:
   ```
   C:\Users\{User}\AppData\Roaming\umbra\settings.json
   ```
3. Запустите UMBRA заново

## 🔐 Безопасность

### Проверка подлинности:

**Проверьте хеш файла:**
```bash
# PowerShell
Get-FileHash UMBRA-Setup-2.1.1.exe -Algorithm SHA256
```

**Официальные хеши публикуются в:**
- GitHub Releases (описание релиза)
- Telegram канал: https://t.me/Umbra_Official_Noxir

### Что НЕ делает UMBRA:
- ❌ Не собирает личные данные
- ❌ Не отправляет телеметрию
- ❌ Не содержит рекламы
- ❌ Не требует регистрации
- ❌ Не изменяет системные файлы

### Что делает UMBRA:
- ✅ Работает локально на вашем ПК
- ✅ Подключается только к указанным сервисам (Twitch, DA)
- ✅ Хранит настройки локально
- ✅ Open-source код на GitHub
