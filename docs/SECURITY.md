# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

### Как сообщить об уязвимости

Если вы обнаружили уязвимость в UMBRA, пожалуйста, **НЕ создавайте публичный Issue**.

**Вместо этого:**

1. **Отправьте приватное сообщение** через GitHub Security Advisory:
   - Перейдите на вкладку "Security" в репозитории
   - Нажмите "Report a vulnerability"
   - Заполните форму с деталями

2. **Или создайте Issue** с меткой `security` и минимальной информацией:
   - Напишите: "Обнаружена потенциальная уязвимость безопасности"
   - Укажите email для связи
   - Мы свяжемся с вами приватно

### Что включить в отчёт

Пожалуйста, предоставьте:

- **Описание уязвимости**
- **Шаги для воспроизведения**
- **Потенциальное влияние**
- **Предлагаемое решение** (если есть)
- **Версия UMBRA**, в которой обнаружена проблема

### Процесс обработки

1. **Подтверждение** - в течение 48 часов
2. **Оценка** - в течение 7 дней
3. **Исправление** - в зависимости от серьёзности:
   - Критическая: 1-3 дня
   - Высокая: 7-14 дней
   - Средняя: 14-30 дней
   - Низкая: следующий релиз

4. **Публикация** - после выпуска патча

### Типы уязвимостей

**Критические:**
- Remote Code Execution (RCE)
- SQL Injection
- Authentication bypass
- Утечка API ключей

**Высокие:**
- XSS (Cross-Site Scripting)
- CSRF (Cross-Site Request Forgery)
- Path traversal
- Privilege escalation

**Средние:**
- Information disclosure
- DoS (Denial of Service)
- Insecure defaults

**Низкие:**
- Minor information leaks
- UI spoofing

### Награды

К сожалению, мы не можем предложить денежные награды (bug bounty), но:

- ✅ Ваше имя будет указано в CHANGELOG
- ✅ Благодарность в Security Advisory
- ✅ Contributor badge на GitHub

### Ответственное раскрытие

Мы просим вас:

- ❌ **Не публиковать** детали уязвимости до выпуска патча
- ❌ **Не эксплуатировать** уязвимость на продакшн системах
- ✅ **Дать нам время** на исправление (обычно 90 дней)
- ✅ **Сотрудничать** с нами для проверки исправления
