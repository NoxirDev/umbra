## 🚀 Как протестировать

### 1. Запустить приложение:
```bash
npm start
```

### 2. Проверить статистику:
```bash
# Открыть Web Dashboard
http://127.0.0.1:4587

# Или через API
curl http://127.0.0.1:4587/v2/statistics
```

### 3. Тестовый донат:
```bash
curl -X POST http://127.0.0.1:4587/v2/donations \
  -H "Content-Type: application/json" \
  -d '{
    "name": "TestUser",
    "amount": "500",
    "message": "Тест уведомления!",
    "currency": "RUB"
  }'
```

### 4. Проверить уведомления:
- Должно появиться системное уведомление Windows
- Клик по уведомлению фокусирует оверлей

### 5. Проверить темы:
- Открыть настройки → Appearance → Themes
- Кликнуть по карточкам тем
- Увидеть визуальный предпросмотр

## 📱 Web Dashboard

**URL:** http://127.0.0.1:4587

**Возможности:**
- 📊 Просмотр статистики в реальном времени
- 👑 Топ-10 донатеров
- ⚡ Быстрые действия (тестовый донат, очистка чата)
- 💬 Отправка сообщений в чат
- 🔄 WebSocket для live updates

**Мобильное использование:**
1. Узнать IP компьютера: `ipconfig`
2. Открыть на телефоне: `http://[IP]:4587`

## 🔔 Уведомления

**Настройки в settings.json:**
```json
{
  "notifyDonations": true,
  "notifyGoals": true,
  "notifyMilestones": true,
  "minDonationAmount": 100
}
```

**Типы уведомлений:**
- 💰 Новый донат (с именем и суммой)
- 🎯 Цель достигнута
- 🎉 Веха достигнута

## 📈 API Endpoints (новые)

```
GET  /v2/statistics              - Вся статистика
GET  /v2/statistics/top          - Топ донатеров
GET  /v2/statistics/sessions     - История сессий
GET  /v2/statistics/export       - Экспорт в JSON
POST /v2/statistics/import       - Импорт из JSON
POST /v2/statistics/reset        - Сброс статистики
GET  /dashboard                  - Web Dashboard
```
