## 🚀 Быстрый старт

### Минимальная настройка (30 секунд):

1. Запусти UMBRA
2. Открой настройки (⚙️ в трее)
3. Введи название Twitch канала в поле "Twitch Channel"
4. Нажми "Применить"
5. Готово! ✅

**Пример:**
```
Twitch Channel: xqc
```

## ✨ Что поддерживается

### 📛 Badges (Значки)
Отображаются рядом с именем пользователя в чате:

- **Broadcaster** 🎥 - владелец канала
- **Moderator** 🔧 - модератор
- **VIP** 💎 - VIP зритель
- **Subscriber** ⭐ - подписчик (с указанием месяцев)
- **Prime** 👑 - Twitch Prime подписчик
- **Turbo** ⚡ - Turbo пользователь
- **Partner** ✓ - партнёр Twitch
- **Staff** 🛡️ - сотрудник Twitch
- **Admin** ⚙️ - администратор Twitch
- **Global Mod** 🌐 - глобальный модератор

**Важно:** Badges загружаются автоматически как настоящие иконки от Twitch, а не эмодзи.

### 😀 Emotes (Эмоции)

#### Twitch Native Emotes
Стандартные эмоции Twitch:
- Kappa, PogChamp, LUL, 4Head, TriHard, BibleThump и т.д.
- Автоматически парсятся из IRC тегов
- Отображаются как картинки в сообщениях

#### BTTV (BetterTTV)
- Глобальные эмоции (доступны везде)
- Канальные эмоции (специфичные для канала)
- Shared эмоции (общие для нескольких каналов)

**Примеры:** monkaS, OMEGALUL, pepeHands, Sadge, COPIUM

#### FFZ (FrankerFaceZ)
- Глобальные эмоции
- Канальные эмоции

**Примеры:** FeelsBadMan, FeelsGoodMan, CatBag, PepeLaugh

#### 7TV
- Глобальные эмоции
- Канальные эмоции
- Поддержка анимированных эмоций (WebP)

**Примеры:** GIGACHAD, Aware, Clueless, Chatting

### 🎉 События

#### Подписки (Subscriptions)
- **Sub** - новая подписка
- **Resub** - продление подписки
- Отображает: tier (1/2/3/Prime), количество месяцев, сообщение

**Пример алерта:**
```
⭐ Username
Tier 1 - 12 месяцев
Спасибо за стрим!
```

#### Подарочные подписки (Gift Subs)
- **Gift Sub** - одиночный подарок
- **Mystery Gift** - массовый подарок сообществу

**Пример алерта:**
```
🎁 Gifter
Tier 1 → Recipient
Подарил подписку!
```

**Пример массового подарка:**
```
🎉 Gifter
5 x Tier 1
Подарил подписки сообществу!
```

#### Рейды (Raids)
Когда другой стример рейдит канал:

**Пример алерта:**
```
🚀 RaiderName
150 зрителей
Рейд!
```

#### Биты (Bits/Cheers)
Поддержка битсами отображается в сообщении:

**Пример:**
```
Username: Great stream! Cheer100
                        ↑
                    [100 bits]
```

## 🔧 Пошаговая настройка

### Шаг 1: Запуск UMBRA

```bash
# Если запускаешь из исходников
npm start

# Или просто запусти UMBRA.exe
```

### Шаг 2: Открытие настроек

**Способ 1:** Кликни правой кнопкой на иконку UMBRA в системном трее → "Настройки"

**Способ 2:** Используй горячую клавишу (если настроена)

### Шаг 3: Ввод названия канала

В окне настроек найди секцию **"Twitch Integration"**:

```
┌─────────────────────────────────────┐
│ Twitch Integration                  │
├─────────────────────────────────────┤
│ Channel Name: [_________________]   │
│                                     │
│ Примеры: xqc, shroud, ninja        │
└─────────────────────────────────────┘
```

**Важно:**
- Вводи только название канала (без https://, без twitch.tv/)
- Регистр не важен (XQC = xqc)
- Без пробелов и специальных символов

**Правильно:**
```
xqc
shroud
your_channel_name
```

**Неправильно:**
```
https://twitch.tv/xqc  ❌
twitch.tv/xqc          ❌
@xqc                   ❌
```

### Шаг 4: Применение настроек

Нажми кнопку **"Применить"** или **"Apply"**

### Шаг 5: Проверка подключения

Открой **DevTools** на окне оверлея:
- Нажми `F12` или `Ctrl+Shift+I`
- Перейди на вкладку "Console"

Должны появиться сообщения:
```
[Twitch] Loaded 112 BTTV emotes
[Twitch] Loaded 89 FFZ emotes
[Twitch] Loaded 156 7TV emotes
[Twitch] Loaded 45 global badges, 12 channel badges
```

**Если видишь эти сообщения - всё работает! ✅**

## ✅ Проверка работы

### Тест 1: Проверка чата

1. Открой Twitch канал в браузере (тот который указал в настройках)
2. Напиши сообщение в чат
3. Сообщение должно появиться в UMBRA

**Что должно отображаться:**
- Платформа badge [TW]
- Твои badges (если есть)
- Твоё имя (цветное)
- Текст сообщения
- Эмоции (если использовал)

### Тест 2: Проверка эмоций

Напиши в чат сообщение с эмоциями:
```
Hello Kappa PogChamp OMEGALUL
```

В UMBRA должны отобразиться:
- `Hello` - текст
- `Kappa` - картинка Twitch эмоции
- `PogChamp` - картинка Twitch эмоции
- `OMEGALUL` - картинка BTTV эмоции

### Тест 3: Проверка badges

Если ты модератор/подписчик/VIP на канале:
- Твои badges должны отображаться как иконки рядом с именем
- Наведи курсор на badge - должна появиться подсказка

### Тест 4: Web Dashboard

Открой браузер и перейди на:
```
http://127.0.0.1:4587
```

В разделе "Quick Actions" нажми **"Send Test Message"**:
- Введи текст с эмоциями
- Нажми "Send"
- Сообщение должно появиться в оверлее

## 🐛 Возможные проблемы

### Проблема 1: Сообщения не появляются

**Причины:**
- Неправильное название канала
- Канал не существует
- Проблемы с интернетом

**Решение:**
1. Проверь правильность написания канала
2. Убедись что канал существует (открой в браузере)
3. Проверь консоль DevTools на ошибки
4. Попробуй переподключиться (измени канал и верни обратно)

### Проблема 2: Эмоции не загружаются

**Причины:**
- Блокировка API запросов
- Проблемы с CORS
- Канал не найден

**Решение:**
1. Проверь консоль DevTools:
   ```
   [Twitch] Failed to load BTTV emotes: ...
   ```
2. Проверь интернет соединение
3. Попробуй другой канал
4. Перезапусти UMBRA

### Проблема 3: Badges отображаются как эмодзи

**Причины:**
- Не загрузились иконки badges
- Проблема с Twitch Badges API

**Решение:**
1. Проверь консоль:
   ```
   [Twitch] Loaded X global badges, X channel badges
   ```
2. Если badges не загрузились - перезапусти UMBRA
3. Проверь CSP (Content Security Policy) в консоли

### Проблема 4: События не показываются

**Причины:**
- Нет прав на просмотр событий (анонимное подключение)
- События не поддерживаются для данного канала

**Решение:**
- События (подписки, рейды, биты) работают только если они происходят в реальном времени
- Для тестирования используй тестовый канал или дождись реального события

### Проблема 5: Высокая нагрузка CPU/Memory

**Причины:**
- Слишком много эмоций загружено
- Большой поток сообщений

**Решение:**
1. Закрой DevTools (если открыт)
2. Уменьши количество отображаемых сообщений в настройках
3. Отключи анимированные эмоции (если будет добавлено)

В настройках UMBRA можно настроить фильтр слов:


Сообщения содержащие эти слова не будут отображаться.

## 📊 Технические детали

### Подключение к IRC

UMBRA использует Twitch IRC WebSocket:
```
wss://irc-ws.chat.twitch.tv:443
```

### Capabilities

Запрашиваемые возможности:
```
CAP REQ :twitch.tv/tags twitch.tv/commands twitch.tv/membership
```

- `twitch.tv/tags` - IRC теги (badges, emotes, цвета)
- `twitch.tv/commands` - команды (подписки, рейды)
- `twitch.tv/membership` - информация о пользователях

### API Endpoints

**BTTV:**
```
https://api.betterttv.net/3/cached/emotes/global
https://api.betterttv.net/3/cached/users/twitch/{channel_id}
```

**FFZ:**
```
https://api.frankerfacez.com/v1/set/global
https://api.frankerfacez.com/v1/room/id/{channel_id}
```

**7TV:**
```
https://7tv.io/v3/emote-sets/global
https://7tv.io/v3/users/twitch/{channel_id}
```

**Twitch Badges:**
```
https://badges.twitch.tv/v1/badges/global/display
https://badges.twitch.tv/v1/badges/channels/{channel_id}/display
```

### Получение Channel ID

Для загрузки канальных эмоций нужен Channel ID:
```
https://decapi.me/twitch/id/{channel_name}
```

## 🔐 Безопасность

### Анонимное подключение

UMBRA использует **анонимное подключение** к Twitch IRC:
```javascript
PASS oauth:justinfan12345
NICK justinfan12345
```

**Это означает:**
- ✅ Не нужен OAuth токен
- ✅ Не нужна авторизация
- ✅ Можно читать любой публичный чат
- ❌ Нельзя отправлять сообщения
- ❌ Нельзя использовать модераторские команды

### Приватность

UMBRA **НЕ собирает и НЕ отправляет** никакие данные:
- Не логирует сообщения на сервер
- Не отправляет статистику
- Не использует аналитику
- Всё работает локально на твоём компьютере

## 💡 Советы и трюки

### Совет 1: Тестирование на своём канале

Лучший способ протестировать - использовать свой канал:
1. Укажи свой канал в настройках
2. Открой свой канал в браузере
3. Напиши сообщения с разными эмоциями
4. Проверь как они отображаются

### Совет 2: Популярные каналы для теста

Если хочешь увидеть много сообщений и эмоций:
- `xqc` - очень активный чат
- `shroud` - средняя активность
- `summit1g` - средняя активность

### Совет 3: Проверка эмоций

Чтобы увидеть все доступные эмоции:
1. Открой DevTools (F12)
2. В консоли введи:
   ```javascript
   window.TwitchEnhanced.getAllEmotes()
   ```
3. Увидишь список всех загруженных эмоций

### Совет 4: Отладка

Для детальной отладки:
1. Открой DevTools (F12)
2. Вкладка "Network"
3. Фильтр: "WS" (WebSocket)
4. Увидишь все IRC сообщения в реальном времени

### Часто задаваемые вопросы

**Q: Можно ли подключиться к нескольким каналам?**
A: Пока нет, только один канал одновременно.

**Q: Можно ли отправлять сообщения в чат?**
A: Нет, UMBRA использует анонимное подключение (только чтение).

**Q: Работает ли с YouTube/Kick одновременно?**
A: Да! Можно подключить Twitch + YouTube + Kick одновременно.

**Q: Почему не все эмоции отображаются?**
A: Загружаются только эмоции доступные на канале. Некоторые эмоции могут быть только для подписчиков.

**Q: Можно ли добавить свои эмоции?**
A: Пока нет, но это планируется в будущих версиях.
