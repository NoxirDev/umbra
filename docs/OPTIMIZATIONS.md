# UMBRA Optimization Report

**Date:** 2026-04-11
**Version:** 2.1.0 → 2.1.1 (optimized)

## Summary

Проведена глубокая оптимизация кода UMBRA для улучшения производительности, снижения потребления памяти и повышения стабильности приложения.

---

## 1. API Server Optimizations

### OBS Pages Caching
- **Проблема:** Каждый запрос к OBS страницам читал файл с диска
- **Решение:** Pre-caching всех OBS HTML страниц при старте сервера
- **Результат:** Мгновенная отдача страниц, снижение I/O операций

### Rate Limiting Optimization
- **Проблема:** Rate limit Map очищался полностью каждую минуту
- **Решение:** Умная очистка только устаревших записей каждые 30 секунд
- **Результат:** Снижение потребления памяти, более точный rate limiting

### WebSocket Optimization
- **Добавлено:** `perMessageDeflate: false` для снижения latency
- **Добавлено:** `maxPayload: 64KB` для защиты от больших сообщений
- **Улучшено:** Автоматическая очистка мертвых соединений при broadcast

### Memory Management
- **Снижен лимит истории:** 1000 → 500 событий
- **Оптимизирована очистка:** Использование `array.length = N` вместо `pop()`
- **Добавлены лимиты:** Защита от переполнения в GET запросах

### Body Reading
- **Добавлено:** Отслеживание размера в реальном времени
- **Добавлено:** Обработка ошибок потока
- **Улучшено:** Более безопасная обработка JSON

## 2. IPC Handlers Optimization

### Polling Rates
- **Click-through polling:** 32ms → 50ms (снижение CPU usage)
- **Resize/Move rate:** Оптимизирован до 16ms (60 FPS)
- **Добавлены константы:** Централизованное управление интервалами

### Click-Through Logic
- **Добавлена:** Быстрая проверка границ окна перед проверкой UI bounds
- **Улучшено:** Автоматическая остановка polling при отсутствии окна
- **Оптимизировано:** Меньше вызовов `setIgnoreMouseEvents`

### Cleanup
- **Рефакторинг:** Вынесены методы `stopResize()` и `stopMove()`
- **Улучшено:** Централизованная очистка ресурсов

---

## 3. Renderer Process Optimization

### Chat UI
- **Добавлено:** `requestAnimationFrame` для батчинга рендеров
- **Оптимизировано:** Использование `DocumentFragment` для DOM операций
- **Результат:** Плавный рендеринг даже при большом потоке сообщений

### Overlay Logic
- **Добавлен:** Debounce для `sendUIBounds()` (100ms)
- **Добавлен:** Debounce для window resize (150ms)
- **Оптимизирована:** Combo система с явным таймером
- **Результат:** Снижение IPC вызовов, меньше нагрузки на main process
