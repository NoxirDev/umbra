# UMBRA - Быстрый старт

> **Quick Start Guide**
>
> Минимальная инструкция для быстрого запуска UMBRA.

---

## ⚡ За 5 минут

### 1. Установка

```bash
# Клонировать репозиторий
git clone https://github.com/NoxirDev/umbra.git
cd umbra

# Установить зависимости
npm install

# Запустить
npm start
```

### 2. Первая настройка

1. Откроется окно настроек
2. Перейдите в **Connections → Twitch**
3. Введите название канала (без #)
4. Нажмите **Save**

### 3. Готово!

Оверлей появится в правом верхнем углу экрана.

## 📱 Web Dashboard

Откройте в браузере: **http://127.0.0.1:4587**

Возможности:
- 📊 Просмотр статистики
- 👑 Топ донатеров
- 💬 Отправка сообщений
- ⚡ Быстрые действия

---

## 🎨 Смена темы

1. Настройки → **Appearance → Themes**
2. Кликните на карточку темы
3. Нажмите **Save**

**6 доступных тем:**
- Default (зелёный)
- Cyberpunk (красный/cyan)
- Minimal (монохром)
- Neon (яркий)
- Dark (тёмный)
- Matrix (матрица)

---

## 🎬 OBS Integration

### Добавить оверлей в OBS:

1. OBS → Источники → **Browser**
2. Скопируйте URL из настроек (**System → OBS**)
3. Вставьте в OBS
4. Размер: **1920x1080** (для полного оверлея)

**4 типа оверлеев:**
- Полный (чат + донаты + цель)
- Только чат
- Только донаты
- Только цель

## 🔔 Уведомления

1. Настройки → **Features → Notifications**

**Типы:**
- 💰 Донаты

## 📊 API

**Base URL:** `http://127.0.0.1:4587`

### Тестовый донат:

```bash
curl -X POST http://127.0.0.1:4587/v2/donations \
  -H "Content-Type: application/json" \
  -d '{
    "name": "TestUser",
    "amount": "100",
    "message": "Тест!",
    "currency": "RUB"
  }'
```

### Получить статистику:

```bash
curl http://127.0.0.1:4587/v2/statistics
```

**Полная документация:** [API.md](API.md)

## 🎯 Горячие клавиши

1. Настройки → **Features → Hotkeys**

## 🐛 Проблемы?

### Оверлей не появляется:
- Проверьте, что приложение запущено
- Посмотрите в системный трей (правый нижний угол)
- Кликните правой кнопкой → Show Overlay

### API не работает:
- Настройки → **System → API**
- Убедитесь, что API включен
- Проверьте порт (по умолчанию 4587)

### Twitch чат не подключается:
- Проверьте название канала (без #)
- Убедитесь, что канал существует
- Проверьте интернет-соединение
