## 📖 Детальные условия

### 1. Использование исходного кода

**Разрешено:**
```
✅ Изучение кода для понимания работы
✅ Использование отдельных функций как референс
✅ Адаптация паттернов для собственных проектов
```

**Запрещено:**
```
❌ Копирование целых модулей (>50 строк) без изменений
❌ Создание "клонов" UMBRA с минимальными изменениями
❌ Использование архитектуры UMBRA "как есть" в других проектах
```

**Пример разрешённого использования:**
```javascript
// ✅ Можно: Изучить паттерн и написать свою реализацию
class MySettingsManager {
  // Своя реализация, вдохновлённая UMBRA
  load() { /* свой код */ }
  save() { /* свой код */ }
}
```

**Пример запрещённого использования:**
```javascript
// ❌ Нельзя: Копирование кода UMBRA напрямую
class MySettingsManager {
  // Скопированный код из UMBRA без изменений
  load() {
    try {
      if (fs.existsSync(this.settingsPath)) {
        const data = fs.readFileSync(this.settingsPath, 'utf8');
        return JSON.parse(data);
      }
    } catch (error) {
      console.error('[Settings] Failed to load:', error.message);
    }
    return this.getDefaults();
  }
}
```

## 🔒 Защита интеллектуальной собственности

### Уникальные элементы UMBRA:

1. **Архитектура:**
   - Модульная структура с менеджерами
   - Система IPC handlers
   - Click-through механизм
   - OBS page caching

2. **Алгоритмы:**
   - Combo система донатов
   - Rate limiting с умной очисткой
   - Atomic file write
   - RequestAnimationFrame batching

3. **UI/UX:**
   - Дизайн оверлея
   - Система тем
   - Анимации донатов
   - Предпросмотр тем

**Эти элементы защищены авторским правом и не могут быть скопированы целиком.**
