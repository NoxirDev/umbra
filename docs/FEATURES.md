# UMBRA v2.1.1 - Новые возможности

## 🎮 Полная интеграция с Twitch

### Что нового?
UMBRA теперь поддерживает расширенную интеграцию с Twitch, включая badges, emotes и события.

### Возможности:

#### 📛 Badges (Значки)
- **Broadcaster** 📡 - владелец канала
- **Moderator** 🔧 - модератор
- **VIP** 💎 - VIP зритель
- **Subscriber** ⭐ - подписчик
- **Prime** 👑 - Twitch Prime
- **Turbo** ⚡ - Turbo пользователь
- **Partner** ✓ - партнёр Twitch
- **Staff** 🛡️ - сотрудник Twitch
- **Admin** ⚙️ - администратор

Значки отображаются рядом с именем пользователя в чате.

#### 😀 Emotes (Эмоции)
- **Twitch Emotes** - нативные эмоции Twitch из IRC тегов
- **BTTV (BetterTTV)** - глобальные и канальные эмоции
- **FFZ (FrankerFaceZ)** - глобальные и канальные эмоции
- **7TV** - глобальные и канальные эмоции

Эмоции автоматически загружаются при подключении к каналу и отображаются в сообщениях чата.

#### 🎉 События
- **Подписки (Sub/Resub)** - новые и продлённые подписки
- **Подарочные подписки (Gift Sub)** - подарки подписок
- **Массовые подарки (Mystery Gift)** - подарки сообществу
- **Рейды (Raid)** - рейды с других каналов
- **Биты (Bits/Cheers)** - поддержка битсами

Все события отображаются как анимированные алерты с соответствующими иконками.

### Технические детали:

**Подключение:**
```javascript
// Автоматически использует enhanced версию
window.TwitchEnhanced.connect('channel_name');
```

**Загрузка эмоций:**
- BTTV API: `https://api.betterttv.net/3/`
- FFZ API: `https://api.frankerfacez.com/v1/`
- 7TV API: `https://7tv.io/v3/`

**IRC Capabilities:**
```
CAP REQ :twitch.tv/tags twitch.tv/commands twitch.tv/membership
```

**Обработка событий:**
- `PRIVMSG` - обычные сообщения с badges и emotes
- `USERNOTICE` - подписки, рейды, биты
- `CLEARMSG` - удаление сообщений
- `CLEARCHAT` - очистка чата / таймауты

### Примеры:

**Сообщение с badges и emotes:**
```

     ↑   ↑  ↑  ↑        ↑     ↑      ↑

     |   |  |  └─ Username
     |   |  └─ Moderator badge
     |   └─ Broadcaster badge

```

## 📊 Расширенная статистика

### Что нового?
UMBRA теперь собирает и хранит детальную статистику о донатах и сообщениях.

### Возможности:
- **Топ донатеров** - список самых щедрых зрителей за всё время
- **История сессий** - статистика по каждому стриму
- **Общая статистика** - всего донатов, сумма, средний донат
- **Экспорт/импорт** - сохранение статистики в JSON

### API Endpoints:

```bash
# Получить всю статистику
GET /v2/statistics

# Топ донатеров (по умолчанию 10)
GET /v2/statistics/top?limit=20

# История сессий
GET /v2/statistics/sessions?limit=10

# Экспорт статистики
GET /v2/statistics/export

# Импорт статистики
POST /v2/statistics/import
Content-Type: application/json
{ ...exported data... }

# Сброс статистики
POST /v2/statistics/reset
```

### Пример ответа:
```json
{
  "ok": true,
  "data": {
    "totalDonations": 150,
    "totalAmount": 45000,
    "totalMessages": 3200,
    "averageDonation": "300.00",
    "topDonators": [
      {
        "name": "TopDonator",
        "amount": 5000,
        "count": 10,
        "firstDonation": "2026-04-01T12:00:00.000Z",
        "lastDonation": "2026-04-11T09:00:00.000Z"
      }
    ]
  }
}
```

## 🔔 Desktop уведомления

### Что это?
Системные уведомления Windows для важных событий.

### Типы уведомлений:
- 💰 **Новый донат** - показывается для каждого доната
- 🎯 **Цель достигнута** - когда сбор завершён
- 🎉 **Веха достигнута** - при достижении промежуточных целей

### Настройки:
```javascript
// В settings.json
{
  "notifyDonations": true,      // Уведомления о донатах
  "notifyGoals": true,           // Уведомления о целях
  "notifyMilestones": true,      // Уведомления о вехах
  "minDonationAmount": 100       // Минимальная сумма для уведомления
}
```

### Как работает:
1. Приходит донат через API или интеграцию
2. Проверяется минимальная сумма
3. Показывается системное уведомление
4. При клике на уведомление - фокус на оверлей

### Пример:
```
┌─────────────────────────────────┐
│ 💰 Новый донат: 500 RUB        │
│ TopDonator: Спасибо за стрим!  │
└─────────────────────────────────┘
```

## 📱 Web Dashboard

### Что это?
Веб-интерфейс для управления UMBRA через браузер.

### Доступ:
```
http://127.0.0.1:4587/dashboard
или
http://127.0.0.1:4587/
```

### Возможности:

#### 📊 Просмотр статистики
- Текущая цель сбора с прогресс-баром
- Статистика сессии (донаты, сумма, сообщения)
- Статистика за всё время
- Топ-10 донатеров в реальном времени

#### ⚡ Быстрые действия
- Тестовый донат
- Очистка чата
- Обновление статистики

#### 💬 Отправка сообщений
- Отправка сообщений в чат оверлея
- Настройка имени отправителя

#### 🔄 Real-time обновления
- WebSocket подключение для мгновенных обновлений
- Автоматическое обновление каждые 10 секунд

### Использование:

1. Запустите UMBRA
2. Откройте браузер
3. Перейдите на `http://127.0.0.1:4587`
4. Управляйте оверлеем из браузера!

### Мобильное использование:
Дашборд адаптивен и работает на мобильных устройствах:
1. Подключите телефон к той же сети
2. Узнайте IP компьютера (ipconfig)
3. Откройте `http://[IP]:4587` на телефоне

## 📝 Примеры использования

### Получить топ донатеров через curl:
```bash
curl http://127.0.0.1:4587/v2/statistics/top?limit=5
```

### Экспортировать статистику:
```bash
curl http://127.0.0.1:4587/v2/statistics/export > stats.json
```

### Импортировать статистику:
```bash
curl -X POST http://127.0.0.1:4587/v2/statistics/import \
  -H "Content-Type: application/json" \
  -d @stats.json
```

### Отправить донат с уведомлением:
```bash
curl -X POST http://127.0.0.1:4587/v2/donations \
  -H "Content-Type: application/json" \
  -d '{
    "name": "TestUser",
    "amount": "500",
    "message": "Тест уведомления!",
    "currency": "RUB"
  }'
```

## 🐛 Известные проблемы

1. **Уведомления не работают** - проверьте настройки Windows (Параметры → Система → Уведомления)
2. **Web Dashboard не открывается** - убедитесь, что API включен в настройках
3. **Статистика не сохраняется** - проверьте права на запись в папку userData
