ИНСТРУКЦИЯ

1. Скопируй нужную ссылку выше

2. В OBS добавь источник "Браузер" (Browser Source)

3. Вставь скопированную ссылку в поле URL

4. Установи размер (указан в подсказках)

5. Включи галочки:

• "Shutdown source when not visible"

• "Refresh browser when scene becomes active"
